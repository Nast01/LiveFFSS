# Lot 8 — Espace admin : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** une carte Admin dans Mon espace (admin = `/me` `data.role == "admin"`) avec choix du serveur, supervision de la compétition, contrôle des données, journal réseau et maintenance.

**Architecture:** le rôle global vient de `/me` et est gardé avec la session ; l'environnement devient un état de l'app lu au lancement et changeable à chaud (les fournisseurs du cœur se reconstruisent, le stockage étant déjà séparé par serveur) ; un journal réseau en mémoire alimenté par `HttpClient` ; les outils admin réutilisent les fournisseurs des lots 4 à 6b.

**Tech Stack:** Flutter 3.47.7 / Dart 3.13.5, flutter_riverpod 3.4, go_router 18, freezed 4, mocktail, fake_async, gen-l10n.

**Spec:** `live_ffss.v2/docs/specs/2026-10-19-lot8-admin-design.md`

## Global Constraints

- Règles de `live_ffss.v2/CLAUDE.md` (toutes sections) : `features` → `data` → `domain` ; `clockProvider` ; `retry: noRetry` ; `ref.mounted` après chaque `await` ; `AppException` seulement ; pas de test de widget ; logique d'affichage dans un `*_formatting.dart` ou un fournisseur, testée ; commentaires qui disent pourquoi ; pas de cycle de dossiers entre features.
- **Aucun agent n'appelle le serveur FFSS** ; fixtures `test/fixtures/recette_1416/` (dont `me_admin.json`).
- **Rien de sensible** dans le journal, le rapport ou les journaux de débogage : ni jeton, ni mot de passe, ni chaîne de requête, ni e-mail, téléphone, date de naissance, numéro de licence.
- Clés locales **globales** (non préfixées par le serveur) à ajouter à `AppEnvironment.globalKeys` : environnement (`api_environment`, déjà là), drapeau « admin vu » ; toutes les autres restent par serveur.
- Lectures à la demande : **6 au plus en vol** ; aucune nouvelle minuterie.
- Traductions : fr de référence, en symétrique (mêmes clés et blocs `@`), pas de clé morte ; `flutter gen-l10n`.
- Avant chaque commit, depuis `live_ffss.v2/` : `flutter analyze`, `flutter test`, `dart format lib test` propres ; fichiers générés modifiés seulement par les fins de ligne : revenir dessus. Commits en français avec `Co-Authored-By`. Ne jamais pousser ni changer de branche (`feat/v2-lot8-admin`).

## Review Focus

1. **Changement de serveur avec des saisies non envoyées ou des rappels planifiés** : rien n'est perdu ni envoyé au mauvais serveur ; les rappels de l'ancien serveur sont annulés → test en Task 2.
2. **Lancement hors ligne d'un admin** : la carte Admin et le choix du serveur restent disponibles → test en Task 1.
3. **Un compte non admin** n'atteint aucun outil admin (fournisseurs qui refusent, pas seulement des boutons masqués) → test en Task 4.
4. **Journal** : jamais de jeton ni de chaîne de requête, borne de 200 respectée → test en Task 3.
5. **Contrôle des données** sur une compétition côtière, vide, ou dont une lecture échoue : partiel et signalé, sans échec global → test en Task 5.
